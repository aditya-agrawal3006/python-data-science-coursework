## Setup

Requires Python 3, Jupyter, pandas, NumPy, SciPy, matplotlib, and requests. Install dependencies from `requirements.txt` and open the notebooks in Jupyter or VS Code.

These notebooks preserve my code cells but omit assignment question sheets, embedded grading/output artifacts, and environment files. Sample CSV datasets needed for the analyses are provided where applicable. The optional salary-data SQLite database is not bundled; see the volcano/SQL project's README.
