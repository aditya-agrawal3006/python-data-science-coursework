# Statistical Analysis & Simulations

Python notebooks applying simulation and hypothesis-testing techniques to probability and college data.

## What it covers
- Analyze streak lengths and sampling distributions with **NumPy**.
- Explore normal, binomial, Poisson, and exponential distributions and the central limit theorem.
- Use **pandas** to clean college data and create summary tables.
- Apply chi-square tests, one-way ANOVA, pairwise comparisons, Pearson correlation, and t-tests using **SciPy**.
- Create visualizations with **matplotlib** to examine relationships and distributions.

## Files
- [`statistics-and-colleges.ipynb`](statistics-and-colleges.ipynb) — original Python analysis cells, grouped by topic.
- [`colleges.csv`](colleges.csv) — supporting sample college data.

## Run
Install dependencies from the repository's `requirements.txt` and open the notebook in Jupyter or VS Code. Run from this directory so `colleges.csv` is found.

**Interpretation note:** Correlation and statistical significance do not by themselves establish causation. These exercises are exploratory, and their assumptions/results have not been independently validated.
